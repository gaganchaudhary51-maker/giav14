# GIA v14 agent rules

- GIA is the commander. Do not invent a second dashboard.
- Preserve working backend and frontend. Minimal diffs.
- Proof required: tests, logs, file changes. Chat "done" is not proof.
- GINI / healthcare expansion is frozen.
- Secrets stay in environment variables. Never write secrets into frontend.
- Mobile-first: iPhone Safari, one left menu, stacked panels, large tap targets.
- CLI tools (Grok Build, Gemini CLI) are panels inside Command Center, not separate apps.
- Sensitive actions need approval + audit.
- Plan before execute. VERIFIED needs evidence.
